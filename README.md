📝 **Social Media Platform**

**Social Media Platform Project** is a simple, modern, front-end and back-end project designed to showcase a fully functional social app experience. It is a multiple-page website featuring smooth user registering, like and comment posts, create and delete posts, follow other persons and a seamless user interface. Users can see posts, add comments and likes, and than they can further use the real app features, and experience a dynamic social app workflow.

🛠️ Built With

HTML5, CSS3

JavaScript (Vanilla JS)

Express JS (Node JS)

Mongo DB (Database)
